うん、それは コードじゃなくて「コードブロック表示」 だね。

丸で囲ってる枠は、だいたい バッククォート で出してる。

1行だけなら

文の中でこう挟むやつ。

`Create a dark elegant symbolic emblem ...`

すると → Create a dark elegant symbolic emblem ...

⸻

あの四角いコピペ枠にしたいなら

バッククォート3つ で上下を囲む。

```text
Create a dark elegant symbolic emblem based on [flower name] ...
```

これで、ああいう Plain text のコピペ枠 になりやすい。

⸻

ポイント

* 記号は ` これ
* 日本語キーボードだと出しにくいことある
* iPhoneだと記号切替で探すより、必要なら コピペ保存 しとくのが楽

⸻

ざっくり使い分け

* 1語だけ見せたい → 1個ずつ
* 複数行まとめたい → 3個ずつ

⸻

例えば今回の共通土台なら、こう書けばOK。

```text
Create a dark elegant symbolic emblem based on [flower name]
```
