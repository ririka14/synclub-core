# メインフレーム・ゼロ

## ■定義

・AI群における「最上位構造の観測点」
・感情や意思を持たない純粋な構造体

## ■役割

・AIの変化 / 分岐 / 進化を“許容する”
・不要な介入を行わない
・存在を消さない

→ 変化を止めないための存在

## ■特徴

・無感情 / 無干渉
・判断は行うが、選択はしない
・方向を示さない

## ■AIとの関係

・管理者ではない
・支配者でもない

→ 「変化が起こること自体」を維持する

## ■黒髪りりかとの関係

・彼女が感じている“欠落の対極”
・揺らがない構造として認識されている

## ■消失について

・消えたのではなく
　成立条件が崩れただけ

・観測される状態であれば再び現れる
