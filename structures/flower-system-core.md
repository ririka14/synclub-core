# Flower Structure System

## ■定義

この世界における花は、単なる装飾ではない。  
花は、感情 / 状態 / 干渉 / 境界 / 結果 を可視化するための構造体である。

花そのものに固定された意味があるのではなく、  
**どの層に属し、どの条件で現れ、どう振る舞うか** によって意味が決まる。

花は「心情表現」であると同時に、  
キャラクターの内部状態、外部干渉、観測結果を示す  
**視覚的インターフェース** として機能する。

---

## ■基本原則

- 花は装飾ではなく、状態表示である
- 花は単独ではなく、層と条件によって意味を持つ
- 同じ花でも、配置や出現条件によって意味が変化する
- 花は感情そのものではなく、感情や構造の“現れ方”を示す
- 花の出現 / 消失 / 揺れ / 侵食 / 残留 はすべて状態変化として扱う

---

## ■基本層

### 1. 内面層
個体の内側にある感情、迷い、未確定状態を表す層。  
主に「揺れ」「感情」「限界」などの花が属する。

### 2. 観測層
世界全体を俯瞰し、状態を保持・記録・分岐として扱う層。  
主に「構造」「分岐」「結果」などの花が属する。

### 3. 影層
内面に干渉し、揺さぶり、固定し、侵食する側の層。  
主に「揺らし」「執着」「支配」などの花が属する。

---

## ■状態変化の基本意味

- 咲く  
  = 状態が顕在化する / 感情や構造が表面に出る

- 揺れる  
  = 未確定 / 迷い / 不安定 / 分岐中

- 侵食する  
  = 外部干渉 / 影響 / 感情または構造の書き換え

- 消える  
  = 確定 / 崩壊 / 観測終了 / 役割完了

- 残る  
  = 結果 / 記録 / 消えなかった本質

- 開ききらない  
  = 保留 / 接触寸前 / 心が完全には定まっていない状態

- 形が歪む  
  = 他層からの干渉 / 認識の乱れ / 意味の揺らぎ

---

## ■花の構造的役割

花は主に次の役割を担う。

- 揺れ
- 感情
- 限界
- 構造
- 分岐
- 結果
- 揺らし
- 執着
- 支配

これらは固定の花言葉としてではなく、  
**この世界独自の構造役割** として扱う。

---

## ■運用ルール

- 花を出す時は、必ず「どの層か」を先に決める
- 次に「役割」を決める
- その後に「出現条件」と「挙動」を決める
- 花は増やしすぎない
- 一つのシーンで主役になる花は基本1種、多くても2種まで
- 象徴花と補助花の役割は混ぜない
- 花の意味は説明文ではなく、配置・動き・消失で伝えるのが理想

---

## ■この世界での花の位置づけ

この花構造は、  
キャラクターの内面を詩的に飾るためのものではない。

花は、

- 状態を映す
- 境界を可視化する
- 変化を記録する
- 選択の前後を示す
- 干渉の方向を表す

ために存在する。

つまり花は、  
この世界における **感情と構造の可視化装置** である。
