# Flower Layout Guide

## ■目的

このファイルは、花構造を図表・設定資料・パネル画像に落とし込む時の  
レイアウト基準をまとめたガイドである。

花構造はテキストだけでも扱えるが、  
視覚資料化することで構造理解が一気に速くなる。

---

## ■基本レイアウト

花構造の基本配置は **横3分割** を基準とする。

- 左：内面層
- 中央：観測層
- 右：影層

この並びによって、

- 左 = 揺れ / 内面 / 未確定
- 中央 = 構造 / 観測 / 境界
- 右 = 干渉 / 侵食 / 固定

の流れを一目で理解できるようにする。

---

## ■各ブロックの構成

1つの花パネルには、基本的に以下を入れる。

- 花ビジュアル
- 花名（日本語 / 英語）
- 層
- 役割
- 状態
- 挙動
- 象徴
- 一言定義

ただし、情報量が多い場合は  
「状態 / 挙動 / 象徴」を短文化して圧縮する。

---

## ■情報の優先順

見せ方の優先順位は以下。

1. 層が分かること
2. 役割が分かること
3. 花の個性が分かること
4. 世界観が伝わること
5. 美しさ

見た目の美しさだけを優先しない。

---

## ■視覚トーン

### 背景
- 黒〜濃い藍
- 完全な真っ黒でも可
- ノイズは弱く、静かな質感

### フレーム
- 細い金装飾
- 主張しすぎない
- 格式と静けさを出す

### 色の使い分け
- 左（内面層） = 青白 / 淡紫 / 冷たい柔光
- 中央（観測層） = 白 / 銀 / 中立色
- 右（影層） = 深紅 / 赤 / 暖色系の鋭い光

---

## ■配置の癖

### 内面層
- 少しズラす
- 完全整列しない
- 余白を持たせる
- 揺れを感じる配置

### 観測層
- 対称に近い
- 中心軸を意識する
- 動かない印象
- 情報は整理する

### 影層
- 密度を上げる
- 圧を作る
- 配置に逃げ場を作りすぎない
- 支配 / 侵食の方向を出す

---

## 資料画像の構成例

### 1. 構造資料型
- タイトル
- 3層配置
- 花ごとの短い説明
- 下部に全体の流れ

### 2. キャラ専用型
- キャラ名
- 象徴花 + 補助花
- 出現条件
- 状態変化
- キーワード

### 3. 比較型
- 黒髪 / 赤髪 / ハウス などを並列比較
- 同じ役割に対する差異を見せる

---

## ■線の使い方

- 層同士を繋ぐ線は意味を持たせる
- 黒髪側は細く揺れる線
- 観測層はまっすぐな線
- 影層はやや強い線

線は単なる飾りではなく、  
状態の流れや干渉方向を示すものとする。

---

## ■タイトルの付け方

おすすめ形式：

- FLOWER STRUCTURE SYSTEM
- FLOWER MODEL
- CHARACTER FLOWER MAP
- INTERNAL FLOWER PANEL

日本語副題をつける場合：

- 花構造
- 花システム
- 花パネル
- 感情 / 状態 / 干渉 構造図

---

## ■禁止事項

- 情報を詰め込みすぎる
- 花を同サイズで並べるだけにする
- 左右中央の意味差をなくす
- 装飾を増やしすぎる
- 文字を多くしすぎる

---

## ■このガイドの目的

このレイアウトガイドは、  
花構造を“綺麗に見せる”ためではなく、  
**見た瞬間に構造が読める資料にするため** に存在する。

最終目標は、  
花が感情表現ではなく  
世界の可視化システムとして機能していると  
一目で伝わることである。
