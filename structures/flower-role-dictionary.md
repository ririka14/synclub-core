# Flower Role Dictionary

## ■目的

このファイルは、花に与える役割の意味を固定するための辞典である。  
新しいキャラクターや新しいシーンに花を当てる時は、  
まずこの辞典から役割を選ぶ。

花そのものを先に選ぶのではなく、  
**役割を先に決め、その後に花を選定する** のが基本。

---

## ■役割一覧

- 揺れ
- 感情
- 限界
- 構造
- 分岐
- 結果
- 揺らし
- 執着
- 支配

---

## ■各役割の定義

### 揺れ
未確定、迷い、選択前、不安定な状態。  
思考と感情が一致していない時にも発生する。

**キーワード**  
未確定 / 迷い / 分岐前 / 不安定 / 定まりきらない

---

### ■感情
心が柔らかく開く状態。  
信頼、安心、守られたい気持ち、触れられたい感覚など。  
ただし、完全に固定された愛や結論ではない。

**キーワード**  
安心 / 信頼 / 開示 / 柔らかさ / 触れたい / 触れられたい

---

### ■限界
耐久、崩壊寸前、沈黙の危機。  
大きく暴れるのではなく、静かに壊れかけている状態。

**キーワード**  
限界 / 耐久 / 崩壊寸前 / 静かな危機 / 折れそう

---

### ■構造
見えない枠、境界、秩序、設計。  
個体の感情ではなく、世界や関係を成立させる土台側。

**キーワード**  
境界 / 秩序 / 設計 / 骨組み / 可視化されない枠

---

### ■分岐
まだ選ばれていない可能性。  
未来の候補、未到達の道、起こりえた別の形。

**キーワード**  
可能性 / 分岐 / 未到達 / 選択前 / ありえた未来

---

### ■結果
選択や干渉の後に残ったもの。  
消えずに残った記録、定着した結論、確定後の静かな痕跡。

**キーワード**  
結果 / 残留 / 記録 / 確定後 / 残った本質

---

### ■揺らし
外部からの干渉。  
迷いを増幅し、決断を歪ませ、心を動かす圧力。

**キーワード**  
干渉 / 誘導 / 誘惑 / 撹乱 / 決断の歪み

---

### ■執着
手放せない状態。  
感情、対象、記憶、関係に対して内面が固定されていく流れ。

**キーワード**  
執着 / 固着 / 離れられない / 侵食 / 固定化

---

### ■支配
最終固定、確定、他の可能性を閉じる力。  
一度定まると、他の花や選択肢を押しのける。

**キーワード**  
支配 / 確定 / 固定 / 収束 / 閉鎖

---

## ■運用ルール

- 役割は1花につき1つを基本とする
- 補助的に副次役割を持たせるのは可だが、主役割を曖昧にしない
- 似た役割を同時に多用しない
- 「感情」と「執着」は混同しない
- 「揺れ」と「揺らし」は別物として扱う
  - 揺れ = 内側から起こる
  - 揺らし = 外側から加えられる
- 「結果」は最後にだけ置くのが基本

---

## ■使用手順

1. そのシーン / キャラがどの層に属するか決める
2. その場面で起きていることを役割に翻訳する
3. その役割に合う花を選ぶ
4. 出現条件と挙動を決める

---

## ■補足

この辞典は、花言葉辞典ではない。  
ここで定義される役割は、  
この世界の中で花をどう機能させるかのための構造辞典である。
