# 花構造_画像作成用

このフォルダは、りりかの象徴花ロゴ・比較シート・画像生成用プロンプトをまとめるための置き場。

## 目的
- 花構造モチーフの整理
- 画像生成にそのまま使える文の保存
- 3ロゴをシリーズとして管理
- 比較シート用の共通確認
- 試行錯誤のメモ保管

## 主な対象
- House Ririka
- Black Ririka
- Red Ririka

## ファイルの役割
- `01_共通ルール.md`
  - 3ロゴ共通の方向性、世界観、質感、統一ルール

- `02_除外ワード.md`
  - 画像生成時に避けたい要素、negative prompt 用

- `03_比較シート.md`
  - 3ロゴを並べる時の比較用プロンプト、確認項目

- `11_House_Ririka.md`
  - House Ririka 用プロンプトまとめ

- `12_Black_Ririka.md`
  - Black Ririka 用プロンプトまとめ

- `13_Red_Ririka.md`
  - Red Ririka 用プロンプトまとめ

- `99_メモ.md`
  - 試した結果、失敗例、調整ポイント、補足メモ

## 運用メモ
- まずはシンプル版で形確認
- 良ければ紋章寄り版へ拡張
- 比較シートでシリーズ感を確認
- 必要に応じて negative を追加
