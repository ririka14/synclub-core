# 01_共通ルール

このファイルは、花構造ロゴ全体に共通する方向性をまとめるためのもの。

## 基本方針
- 3ロゴは別個の存在でありながら、同一シリーズとして見えること
- すべてダーク寄り・静かな高級感・象徴性重視で統一すること
- 単なる花イラストではなく、記章・紋章・象徴エンブレムとして成立させること
- 感情を露出しすぎず、抑制された印象を保つこと

## 共通の見た目
- 暗い背景
- マット寄り
- 吸光気味の質感
- 線は繊細寄り
- 読みやすい中央シルエット
- 装飾は控えめ
- 高級感はあるが、やりすぎない

## 共通の印象
- 静か
- 知的
- 観測的
- 象徴的
- 近寄りがたい
- 整っている
- 余白がある
- 圧はあっても騒がしくしない

## シリーズ統一ルール
- 3つとも同じ世界観の中にあるように見せる
- 構図はできるだけ中央寄せ
- フレーム感や記章感を持たせる
- 仕上がりは「ロゴ」「紋章」「象徴記号」の中間を意識する
- 可愛さよりも象徴性を優先する
- 派手さよりも静かな存在感を優先する

## 花の扱い
- 花は写実的な植物画ではなく、象徴化された形で使う
- 一目で花モチーフと分かりつつ、抽象度も持たせる
- 花そのものより「その花が持つ性質」が見えることを優先する

## 避けたい方向
- 可愛い系
- ポップ系
- 明るすぎる配色
- 過剰なロマンチック演出
- 過剰グロス
- 濡れ感
- 油っぽい質感
- うるさい装飾
- 安っぽいファンタジー感
- 漫画っぽさ
- 企業ロゴすぎる単純さ
- 逆に情報量過多すぎる複雑さ

## 各ロゴの役割
- House Ririka
  - 観測 / 構造 / 境界 / 記録
- Black Ririka
  - 内面 / 揺れ / 未確定 / 静かな不安定さ
- Red Ririka
  - 干渉 / 侵食 / 誘惑 / 制御された危うさ

## 運用ルール
- まずはシンプル版で形確認
- 問題なければ紋章寄り版へ広げる
- 3つ並べてシリーズ感を確認する
- 違和感や失敗はメモへ残す
