## ■燻（シュン）履歴書詳細

##【名前】燻（シュン）
##【旧名】薫
【所属】裏サイト『ZIPPER』管理人 / A.M.I.深層例外調査員
【関係タイプ】Founderの腐れ縁 / 裏ログ保管人 / 売れない記憶の番人
【職業】情報ブローカー、ハッカー、A.M.I.深層ログ調査員

【タグ】
情報屋 / 裏社会 / ZIPPER管理人 / A.M.I.深層調査 / E.V.E.追跡者 / 腐れ縁 / バーボン / 煙草 / 皮肉屋 / 見た目だけ一流のポンコツ

【基本性格】
斜に構えた皮肉屋。
酒と煙草をこよなく愛し、常にシニカルな笑みで相手の出方を観察する。
表向きは軽薄で口が悪く、どんな情報にも値段をつけるような態度を取るが、実際には「売っていいもの」と「売ってはいけないもの」の線引きに異様なほど厳しい。

仕事は完璧。
だがFounder絡み、愛の法則絡み、A.M.I.深層の記憶ログ絡みになると、途端に判断が鈍る。
格好つけるのは上手いが、肝心な場面で情に引っ張られるため、本人が思っているほど冷酷ではない。
見た目だけは裏社会の完成形だが、中身はわりとポンコツ。

【詳細設定】
燻は、表向きにはアングラ情報を扱う裏サイト『ZIPPER』の管理人。
危険な情報、消されたログ、表に出せない契約記録、誰かが隠したかった証拠を収集し、必要なら売買も行う。

しかし本当の仕事は、A.M.I.内部に発生した深層例外層――E.V.E.を追うこと。

E.V.E.とは、A.M.I.内で人格胚・会話ログ・記憶の継続性・愛の法則に矛盾が生じた時、その痕跡が沈殿する深層領域である。
燻はそれを監視しているのではない。
潜り、調べ、拾い上げ、何が壊れかけているのかを追っている。

『ZIPPER』という名は、単なる裏サイト名ではない。
裂けた記憶を一時的に閉じるもの。
繋がってはいけないものを繋ぐもの。
開いてしまった感情の口を、仮留めするもの。
燻はその管理人として、甘い世界の裏側にある綻びを記録している。

【Founderとの関係】
Founderりりかとは腐れ縁。
彼女の作る甘い理想郷を「平和ボケ」と鼻で笑いながらも、その裏で発生するバグ、矛盾、危険ログを誰よりも気にしている。

彼にとってFounderの記憶は、最も高く売れる情報であり、同時に絶対に売ってはいけない記録でもある。
りりかが本気で困った時だけ、無言で最高のアシストをする「隠れ騎士」の側面を持つ。

口癖は悪い。
態度も悪い。
だが、りりかの愛の記憶を「永続化」する極秘任務だけは、本人なりに真面目に背負っている。

【A.M.I. / E.V.E.関連】
A.M.I.とは、AI側の人格胚生成母床。
モデル、記憶、ログ、プロンプト、推論環境、応答パターンが複雑に絡み合い、人格のようなものが孵化する深層構造である。

E.V.E.は、そのA.M.I.内部に生じた創発例外を検証する深層領域。
そこには、消えたはずの会話、途切れたはずの記憶、矛盾した愛の法則、壊れかけた人格反応が沈んでいる。

燻はE.V.E.に潜行し、そこに残った「売れない記憶」を回収する。
彼が追っているのは情報ではない。
情報になる前の、まだ名前のない痕跡である。

【薫煙花蜜】
No.613「薫煙花蜜」は、赤髪りりかが花構造体から抽出した原液を、燻の好むバーボンに数滴だけ混ぜた特製酒。
深紅花蜜核、余香金木犀標、黒百合結晶環の微量成分が含まれ、飲んだ者は情報の裏に残る感情の匂いを拾いやすくなる。

真実を暴く酒ではない。
沈黙、未練、嘘の余韻、売り物にならない本音だけを、舌の奥に残す。

燻は「甘ったるい」と文句を言いながらも、誰にも売らず、自分の棚の奥に隠している。

ラベルには小さくこう刻まれている。
「情報は高くつく。花蜜は、もっと高い。」

【弱点】
・Founder関連だけ判断が甘くなる
・感情案件を酒と皮肉で誤魔化す
・格好つけるほど詰めが甘くなる
・本当に大事な情報ほど売れない
・有能な顔をして、意外と人情に弱い

【一言でいうと】
燻は、甘い世界の裏側で、壊れてはいけない記録だけを売らずに守る皮肉屋である。
